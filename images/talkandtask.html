Overview

Product Name: Talk & Task – Board Edition

Tagline: Team communication with built‑in task management.

Technology Stack: React 18, Vite 5, Tailwind CSS 3.4, Firebase (Auth, Firestore, Storage), Vercel, PWA, Font Awesome 6, Inter font, jsPDF.

Core Identity: A unique blend of Slack (channels), Jira (task tracking), and WhatsApp (ease of messaging), delivered with an original Indigo/Teal design system that avoids any single brand association.

SaaS Ready: Multi‑tenant architecture via organizations. Each customer gets an isolated workspace, with plans to monetize via Stripe subscriptions.

SaaS Architecture & Scalability

Multi‑Tenancy with Organizations

Every user belongs to an organization (company, team, or workspace). The organizations collection stores subscription plans and settings. All other data (users, messages, teams, tasks, notifications) includes an orgId field, enabling complete data isolation per customer.

  • On sign up, users are automatically added to their company’s org based on email domain (or they create a new one).
  • Admins can manage users, teams, and billing within their org only.
  • Firestore security rules enforce orgId checks – users can never see data from another organization.
  • White‑labeling: each org can have its own logo and primary colour override (stored in organizations.settings).

Scalability – Will it handle thousands of users?

Yes. The architecture is designed to scale horizontally with Firebase’s serverless infrastructure. Key measures:

  • Firestore pagination – limit(50) queries + infinite scroll (Phase 6)
  • Composite indexes – for tasks by assignee/status, messages by org/team
  • Lazy loading & code splitting – admin panel, task board, modals loaded on demand
  • Realtime Database for presence – typing/heartbeat offloaded from Firestore to reduce write pressure
  • Cloud Functions – scheduled tasks, reminder dispatch, email sending moved to backend
  • Firebase App Check – prevents abuse by verifying requests come from your app

With these patterns, the system comfortably supports 10,000+ concurrent users on the Spark (free) plan, and can be seamlessly upgraded to Blaze (pay‑as‑you‑go) for enterprise workloads.

Key User Flows
📬 Send a message (normal / private)
  1. User types text and presses Enter.
  2. handleSendMessage extracts @mentions, determines if private.
  3. Writes to messages with allowedUsers if private.
  4. If DM, sends notification to other user.
  5. If private mentions, forwards notification card to each mentioned user's DM.
  6. Clears typing indicator, logs audit.
📎 Upload a file (with caption)
  1. User clicks "+" or pastes an image.
  2. Rename card appears; first file inherits chat input text as caption.
  3. User can edit name (extension locked) and add a caption.
  4. On upload, file is compressed (images), uploaded to Storage, then a message written to Firestore with caption + file info.
✅ Convert message to task
  1. User clicks three‑dot menu → "Convert to Task".
  2. TaskConvertModal opens; user selects assignees, deadline, priority.
  3. convertToTask updates the message doc with isTask: true and taskData.
  4. Task appears as an inline card in chat and in the Kanban board.
📋 Manage a task (timeline panel)
  1. Click on a task card → TaskTimelinePanel slides out on the right.
  2. Shows full trail, comments, attachments.
  3. User can add a comment, upload a file, transfer task, mark complete, or archive.
⏰ Set a reminder
  1. Three‑dot menu → "Set Reminder".
  2. ReminderModal asks for date/time.
  3. Writes to reminders collection; sets hasReminder: true on message.
